# TRASHAWAY pitch page

Static one-page pitch for TRASHAWAY (Team DreamRise, NITDA Innovation Challenge 2.0), with the demo video embedded.

Open `index.html` in a browser, or serve this folder (for example with GitHub Pages). No build step. Fonts load from Google Fonts; the page still works offline with fallback fonts.

Items in [square brackets] are placeholders to fill in before pitching.
